# Nitesh Sharma — Personal Portfolio

A personal portfolio website for Nitesh Sharma, a Computer Science student interested in data, technology, and building useful things.

The site is designed to feel like a personal notebook and workbench rather than a traditional resume. It presents Nitesh's background, interests, projects, skills, education, credentials, and short-form thoughts.

## Sections

- **Me** — Introduction, current interests, personal background, and a collapsed inline Thoughts section.
- **Work** — Projects, technologies, skills, education, and credentials.

The portfolio uses a warm, editorial visual style with responsive layouts, expandable project and thought details, and simple navigation between the main sections.
